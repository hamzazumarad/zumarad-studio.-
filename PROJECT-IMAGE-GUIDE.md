# Zumarad Studio — Real Project Image Workflow

## Strict project separation
Each project has its own folder and gallery. **Never combine screenshots from different projects.**

### LeadForge AI
`assets/portfolio/leadforge-ai/`
- 18 real supplied screenshots
- Only LeadForge AI screens/assets belong here.

### Titan Fitness
`assets/portfolio/titan-fitness/`
- 9 real supplied screenshots
- Only Titan Fitness screens/assets belong here.

### Future projects
Put new supplied screenshots in:
`assets/portfolio/incoming/`

Then create a new project folder and a separate project object in `js/data.js`.

## Rule
One project = one story = one hero image = one gallery.
No mixed screenshots, stock images, or guessed project associations.
