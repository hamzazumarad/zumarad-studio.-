# Naming Convention

Folders
lowercase

Example

css/
js/
assets/
docs/

Files

kebab-case

Example

portfolio.css

why-choose.css

main.js

scroll-animation.js

---

# HTML Rules

Use Semantic HTML

<header>

<nav>

<main>

<section>

<article>

<footer>

No inline CSS

No inline JavaScript

Meaningful class names

Proper indentation

Comments before every section

---

# CSS Rules

Use Variables

Use Component Based CSS

Avoid !important

Use Flexbox first

Use Grid when required

Keep selectors short

Follow mobile-first approach

---

# JavaScript Rules

Separate files

One responsibility per file

No global variables

Use const by default

Use let only when needed

Create reusable functions

Avoid duplicate code
